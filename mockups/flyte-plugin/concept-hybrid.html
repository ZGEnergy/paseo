Project switcher — open state, phone, light

The header's muted project text is the trigger (a Pressable with a small ChevronDown Icon — plugins have no DropdownMenu primitive, so this is hand-built View/Text). Tapping expands a transient inline list below the header; selecting a project re-keys the runs queries and collapses it. The three projects are real — pulled from GET /api/v1/projects on the cluster. The selection is sticky: the plugin server records the last viewed project in a small JSON state file (machine-local work is the sanctioned server-half job; there is no plugin storage API), so the next open starts where you left off, on any device. The cluster usage card is project-independent and stays as-is.
